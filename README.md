# MSS app releases

Signed Android builds of **MSS (MSME Schemes Search)**, the app that helps Indian micro, small and medium enterprises find government schemes.

- **Download:** open [Releases](../../releases/latest) and install the `.apk`. Android may ask you to allow installs from your browser the first time.
- **Updates:** the app checks this page and shows "Update available" with what changed. Each new build installs over the old one and keeps your data.
- Every APK is built by GitHub Actions and signed with the MSS release key. Android only installs an update when that signature matches.

This repository holds releases only; the source code is private.
